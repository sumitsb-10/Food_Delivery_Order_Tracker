# Requirements

## 1. Functional Requirements

- User registration and login
- Restaurant and menu management
- Browse restaurants and food items
- Add/remove items from cart
- Place and track orders
- Update order status
- Store order and payment details
- View order history

## 2. Non-Functional Requirements

- Secure user authentication
- Reliable database operations
- Responsive API performance
- Data validation and error handling
- Maintainable and modular code
- Scalable database design

## 3. Technical Requirements

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- REST API
- Git/GitHub

## 4. Database Requirements
The database should maintain:

- Users
- Restaurants
- Menu items
- Orders
- Order items
- Payments
- Delivery/order status

## 5. Development Requirements

- Use environment variables for configuration
- Maintain database schema in `schema.sql`
- Initialize the database using `init_db.py`
- Keep application logic modular
- Provide clear API endpoints and documentation
